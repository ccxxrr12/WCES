## 二、人员定位性能优化

### 2.1 当前定位方案概述

**核心架构**: 子载波方差-相位多普勒混合加权质心方案

```
CSI 原始数据
    │
    ├─ 子载波幅度方差 Var[A_k] ──→ 角度映射 θ_k ──→ 热力图 ──→ 峰值提取 → 位置
    │                                                    ↑
    ├─ 相位多普勒 FFT ──→ BVP 速度剖面 ──→ 注意力加权
    │                                                    ↑
    ├─ 多站融合 (N节点注意力) ──→ 交叉节点相干性增强
    │                                                    ↑
    └─ 场模型 SVD ──→ 环境模式分离 ──→ 人体扰动残差
    
    最终: 加权质心 / 峰值坐标 → 卡尔曼平滑
```

### 2.2 优化内容

#### 优化 1: 热力图分辨率提升

**文件**: [signal_processing.rs](file:///d:/CODING/Repository/WCES/rust-server/crates/wifi-densepose-sensing-server/src/signal_processing.rs#L28)

| 参数 | 优化前 | 优化后 | 影响 |
|------|--------|--------|------|
| 网格分辨率 | 20×20 | **40×40** | 空间分辨率提升 4 倍 |
| 高斯 blob spread | `0.5 + weight * 2.0` | `0.3 + (1.0 - weight) * 1.5` | 高方差方向更聚焦 |
| 半径映射 | `center * 0.8 * √weight` | `center * (0.2 + 0.6 * (1-weight))` | 强信号→近距离估计 |

**改进原理**: 
- 40×40 网格将空间分辨率从 0.6m/cell 提升到 0.3m/cell
- 自适应 spread 使高置信度方向（高方差子载波）获得更窄的 blob，减少方向模糊
- 逆距离映射利用了"信号越强→距离越近"的物理特性

#### 优化 2: 幅相融合方差

**文件**: [signal_processing.rs L210+](file:///d:/CODING/Repository/WCES/rust-server/crates/wifi-densepose-sensing-server/src/signal_processing.rs#L210)

新增 `compute_subcarrier_variances_combined()` 函数，融合幅度方差和相位方差：

```
Combined_Var[k] = Var[A_k] + 0.3 × Var[φ_k]
```

**改进原理**: 相位方差对微动作（呼吸、心跳）更敏感，幅度方差对大动作（行走、挥手）更敏感，两者融合提供更全面的空间感知。

#### 优化 3: 亚像素级峰值精化

**文件**: [field_localize.rs](file:///d:/CODING/Repository/WCES/rust-server/crates/wifi-densepose-sensing-server/src/field_localize.rs#L105)

新增 `refine_peak_subpixel()` 函数，通过 3×3 邻域加权质心实现亚像素精度：

```
x_refined = Σ(w_i × x_i) / Σ(w_i)    (i ∈ 3×3 neighborhood)
```

**改进原理**: 类似计算机视觉中的亚像素角点检测，利用邻域强度分布将定位精度从 cell 级提升到亚 cell 级。

#### 优化 4: 高方差子载波选择

新增 `select_top_subcarriers()` 函数，选择方差最高的 K 个子载波进行聚焦分析，减少噪声子载波的干扰。

## 三、呼吸与心跳监测优化

### 3.1 当前检测方案

**呼吸检测** ([breathing.rs](file:///d:/CODING/Repository/WCES/rust-server/crates/wifi-densepose-mat/src/detection/breathing.rs)):
- FFT + Hanning 窗，检测 0.1-0.67 Hz (6-40 BPM)
- 频谱峰值 + 正则性 + 置信度评估

**心跳检测** ([heartbeat.rs](file:///d:/CODING/Repository/WCES/rust-server/crates/wifi-densepose-mat/src/detection/heartbeat.rs)):
- 微多普勒分析，notch 滤波去除呼吸分量
- 检测 0.8-3.0 Hz (48-180 BPM)

### 3.2 优化内容

#### 优化 1: 增强版呼吸率估计 — 多子载波融合

**文件**: [signal_processing.rs L185+](file:///d:/CODING/Repository/WCES/rust-server/crates/wifi-densepose-sensing-server/src/signal_processing.rs#L185)

新增 `estimate_breathing_rate_enhanced()` 函数：

| 特性 | 原始方案 | 增强方案 |
|------|---------|---------|
| 子载波使用 | 全部平均（丢失空间信息） | Top-8 高方差子载波 |
| 频率候选数 | 9 个 | **15 个**（更细频率分辨率） |
| 预处理 | 仅去均值 | 去均值 + 移动平均带通 |
| 融合策略 | 单一 Goertzel | **多子载波加权投票** |
| 噪声阈值 | 3× 平均功率 | 2× 平均功率（更灵敏） |

**算法流程**:
1. 计算各子载波方差，选取 Top-8 高 SNR 子载波
2. 对每个子载波的时间序列做去均值 + 移动平均带通
3. 在 [0.1, 0.5] Hz 范围内用 15 个 Goertzel 滤波器检测
4. 按子载波方差加权，投票选出最佳频率

#### 优化 2: 运动伪影抑制

**文件**: [breathing.rs L207+](file:///d:/CODING/Repository/WCES/rust-server/crates/wifi-densepose-mat/src/detection/breathing.rs#L207)

新增 `suppress_motion_artifacts()` 方法：

```
1. 7 点滑动窗口中位数滤波
2. 计算中位数绝对偏差 (MAD)
3. 偏差 > 3×MAD×1.4826 的采样点被衰减至中位数附近（保留 10%）
```

**改进原理**: 运动伪影产生的大幅度尖峰会污染呼吸频谱，MAD 检测能有效识别并衰减这些尖峰，同时保留呼吸信号。

#### 优化 3: 心跳自适应带通滤波

**文件**: [heartbeat.rs L296+](file:///d:/CODING/Repository/WCES/rust-server/crates/wifi-densepose-mat/src/detection/heartbeat.rs#L296)

新增 `adaptive_bandpass()` 方法：

| 参数 | 值 | 说明 |
|------|-----|------|
| 滤波器类型 | 二阶 IIR Biquad (RBJ cookbook) | 级联高通+低通 |
| 通带 | 0.8 - 3.0 Hz | 48-180 BPM |
| Q 因子 | 0.707 | Butterworth 平坦响应 |
| 采样率 | 自适应 | 根据实际 CSI 采样率配置 |

**改进原理**: 在去除呼吸分量后，心跳信号仍然很弱。带通滤波器进一步抑制带外噪声，提高心跳检测 SNR。

#### 优化 4: 检测参数调优

## 四、性能测试方案

### 4.1 静态定位测试

**测试环境**:
- 房间尺寸: 6m × 4m
- ESP32-C5 节点: 4 个，部署在房间四角（高 1.5m）
- AP: 1 个 802.11ax AP，信道 36 (5GHz)
- 目标: 1 人静止站立

**测试点**: 在房间内选取 20 个已知坐标点（间距 1m），每个点采集 60s 数据

**指标**:
- 平均定位误差 (MAE)
- 95% 置信区间
- CDF (累积分布函数)

**目标**: MAE ≤ 0.5m（多节点），≤ 1.0m（单节点）

### 4.2 动态跟踪测试

**测试场景**:
- 人员沿预设路径行走（直线、L 型、环形）
- 速度: 0.5 m/s, 1.0 m/s, 1.5 m/s
- 每条路径重复 5 次

**指标**:
- 跟踪延迟 (end-to-end latency)
- 轨迹 RMSE
- 丢失率

**目标**: 延迟 ≤ 100ms，RMSE ≤ 1.0m

### 4.3 呼吸/心跳准确率测试

**参考设备**: 医用指夹式血氧仪 (SpO2 + 脉率) + 呼吸带

**测试方案**:
- 受试者: 10 人（不同体型/性别/年龄）
- 每人采集 5 分钟 CSI 数据
- 对比 CSI 估计值与参考设备读数

**指标**:
- 呼吸率: 平均绝对误差 (BPM)
- 心率: 平均绝对误差 (BPM)
- 检测成功率 (在 ±2 BPM 内的比例)

**目标**: 呼吸准确率 ≥ 90%，心跳准确率 ≥ 85%

| 测试项 | 方法 | 预期结果 |
|--------|------|---------|
| CSI 采样率 | 统计 1 分钟内 CSI 回调次数 | STA: ~15 Hz, NDP: ~50 Hz |

## 七、系统性能瓶颈与未来优化方向

### 7.1 当前瓶颈

| 瓶颈 | 严重度 | 说明 |
|------|--------|------|
| **单天线限制** | 高 | 1T1R 无法做到达角 (AoA) 估计，角度分辨力完全依赖子载波虚拟阵列 |
| **CSI 采样率** | 中 | 即使 NDP 注入，50 Hz 仍低于专用雷达（>1 kHz），限制心跳检测精度 |
| **室内多径** | 高 | 方舱/废墟环境多径严重，子载波→角度映射存在模糊 |
| **计算资源** | 中 | ESP32-C5 384KB SRAM 限制了本地处理能力，主要计算在服务器端 |
| **缺乏真实数据** | 高 | 当前 `simulate_rssi_measurements` 仍为模拟数据，需真实 CSI 数据验证 |

### 7.2 未来优化方向

#### 短期 (1-3 个月)

1. **CSI 指纹数据库构建**: 在真实方舱环境采集多位置 CSI 指纹，训练轻量 CNN 回归模型
2. **FTM 测距集成**: 利用 ESP32-C5 的 802.11mc FTM 能力，补充 CSI 定位的距离信息
3. **多节点时间同步**: 实现 μs 级时间同步，支持 TDOA 定位
4. **真实数据验证**: 替换所有模拟数据为真实 CSI 采集数据

#### 中期 (3-6 个月)

5. **轻量 CNN 部署**: 参考 LiteCSINet 架构，在服务器端部署 CSI→坐标端到端回归模型
   - 输入: 56 子载波 × 256 时间窗 CSI 幅度+相位
   - 输出: (x, y) 坐标
   - 预期精度: 0.3-0.5m
6. **域自适应迁移学习**: 空房间校准 → 运行时自适应，解决环境变化问题
7. **VMD (变分模态分解)**: 替代 FFT 做呼吸/心跳分解，更好的非平稳信号处理能力
8. **多参数融合**: 定位 + 呼吸 + 心跳 + 运动 联合估计，互相约束

#### 长期 (6-12 个月)

9. **WiFiGPT 探索**: 利用现有 LLM 基础设施，探索 CSI 时序 → 位置+生命体征的 LLM 回归
10. **联邦学习**: 多个方舱节点联邦训练定位模型，保护患者位置隐私
11. **UWB 补充**: 在关键区域部署 UWB 锚点，提供 10cm 级定位基准
12. **边缘 AI 加速**: 利用 ESP32-C5 的 GDMA + BitScrambler 做边缘端 CSI 预处理
